# Comanda

## O que é
**Comanda** é uma fila de jobs escrita em Go usando PostgreSQL como armazenamento, onde a aplicação envia jobs via HTTP e os workers se dividem para realizar as tarefas de maneira concorrente.

## Por que existe
Um projeto para demonstrar meu progresso sobre a linguagem Go, banco de dados e testes
